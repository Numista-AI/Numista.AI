# _checklists_source/

**Source PDF files** for the downloadable coin program checklists.

These files are:
- **Gitignored** (excluded by `**/*.pdf` in root `.gitignore`) — they are NOT in the repo
- **Not bundled in the app** — they live in the Flutter project root for convenient local access, not in `assets/`
- **Served from GCS** — the live checklist downloads are hosted in Google Cloud Storage, not from this directory

## Generating / Updating Checklists
The PDFs are generated by `numista_backend/_scripts/generate_labels.py` and related scripts.
To regenerate, run the appropriate script from `numista_backend/_scripts/`.

## Contents (33 files)
Washington Quarters, State Quarters, American Women, ATB, Presidential, Native American,
Lincoln Cents, Roosevelt Dimes, Kennedy Half, Morgan/Peace Dollars, American Eagle, 
Innovation, Proof Sets, and more.

> **Note:** Two duplicate files with double-underscore names were deleted June 16, 2026.
> The canonical versions (single underscore) are the correct ones.
