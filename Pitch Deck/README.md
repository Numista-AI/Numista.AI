# Numista.AI Pitch Deck Package (Google Cloud for Startups)

This folder contains the complete, interactive pitch deck package created for the **Google Cloud for Startups Program**, highlighting **Morgan AI**, our **Senior Collection Preservation & Estate Planning mission**, and our **Google Cloud Native Architecture**.

## Files in this Directory

1. **`pitch_deck.html`** *(Recommended)*
   - A standalone, interactive pitch deck web application.
   - **How to View:** Double-click `pitch_deck.html` to open it in Chrome, Edge, or any browser.
   - **Features:**
     - 12 interactive slides with dark Google Cloud/Gemini aesthetic.
     - **Slide 4:** Live interactive **Morgan AI Chat Simulator** with pre-built senior collector questions.
     - **Slide 5:** Live interactive **Estate Division Simulator** with sliders for collection value and heirs.
     - **Slide 7:** Clickable **Google Cloud Architecture Explorer** detailing Vertex AI, Document AI, Cloud Run, Firestore, BigQuery, and GCS.
     - Full keyboard navigation (Arrow keys, Space, PageUp/PageDown, Home/End, F for fullscreen).

2. **`NUMISTA_AI_GOOGLE_STARTUP_PITCH_DECK.md`**
   - The full written executive pitch deck, speaker tracks, slide-by-slide notes, and Google Cloud strategic alignment.

3. **`pitch_deck_screen.dart`**
   - The complete Flutter UI screen ready to be enabled as a hidden link/page inside `numista_mobile` whenever you choose.

## Key Talking Points for Google Cloud Reviewers
- **The $84T Wealth Transfer ("The Silver Tsunami"):** Millions of senior collectors hold $38B in uncatalogued physical numismatic assets.
- **Morgan AI:** Context-aware, patient conversational AI powered by Google Vertex AI & Gemini 3.5.
- **Estate Preservation Engine:** Algorithmic fair-share division solver + token-gated Attorney Portal preventing family disputes.
